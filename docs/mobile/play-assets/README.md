# Google Play 이미지 초안

- `icon.png`: 512 × 512, RGB, 불투명 PNG 앱 아이콘.
- `feature.png`: 1,024 × 500, RGB, 불투명 PNG 소개 이미지.
- 같은 이름의 SVG는 수정 가능한 벡터 원본이다. 기존 초록색·병아리 브랜드를 바탕으로 만든 소개용 그래픽이며 실제 앱 화면 캡처가 아니다.
- 실제 화면은 Android 가상 기기 검사 산출물의 macro/home/settings/privacy 캡처에서 확인한다. 제출에는 최종 배포본과 일치하는 실제 앱 스크린샷 두 장 이상을 사용한다. 사용자 집 정보·토큰이 담긴 캡처를 사용하지 않는다.
- 이미지 내용·개발자명·지원 이메일·국가·연령 대상·가격은 소유자 최종 검토 뒤 Play Console에 등록한다. 등록 및 심사 통과를 뜻하지 않는다.

공식 규격: https://support.google.com/googleplay/android-developer/answer/9866151?hl=en
