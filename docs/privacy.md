# Mini Workstation Hub 개인정보 처리 안내

업데이트 2026-11-26 · 개발 버전 0.5

이 앱은 로그인한 Windows 사용자 권한으로 동작합니다. 개발자에게 보내는 사용 분석·광고·영상 수집 서버를 포함하지 않습니다.

창 배치·기기 연결·영상 보관 기록·선택한 파일과 완성 영상은 사용자가 지정한 PC 폴더에 저장합니다. 연결 정보와 설정의 기본 위치는 로컬 앱 데이터의 `MinaDesk/WorkstationHub`입니다. Home Assistant 토큰, Google OAuth 클라이언트·갱신 토큰과 업로드 세션은 해당 Windows 사용자용 DPAPI로 암호화합니다. 설정 백업에도 암호화된 값이 들어갈 수 있습니다.

사용자가 연결한 Home Assistant에는 기기 상태 조회와 요청한 제어 명령을 보냅니다. Home Assistant·Music Assistant 및 해당 기기 제조사의 서비스는 각각의 설정과 정책을 따릅니다.

Google 연결을 선택하면 기본 브라우저에서 Google 계정 승인을 받습니다. 앱은 YouTube 업로드 및 내 영상 상태 읽기 권한을 요청합니다. 수동 업로드를 확인하거나 자동 업로드를 켰을 때 선택한 영상·제목·설명과 비공개 상태를 Google의 YouTube Data API에 보냅니다. 업로드 완료 후 처리 성공과 비공개 상태를 조회합니다. 개발자는 계정 토큰이나 집 안 영상을 수신하지 않습니다. Google·YouTube의 보관·계정 정책이 별도로 적용됩니다.

Google 계정의 연결된 앱 관리에서 권한을 철회할 수 있습니다. 앱을 종료하고 로컬 설정·기록을 제거하면 저장된 연결 정보를 지울 수 있습니다. 원본·완성 영상과 이미 올린 YouTube 영상은 별도로 관리합니다. 이 앱은 휴대폰 갤러리 파일이나 업로드한 영상을 자동 삭제하지 않습니다.

매크로 스크린샷은 화면 내용을 지정한 로컬 폴더와 클립보드에 저장합니다. OBS 설정을 사용하면 사용자가 선택한 OBS WebSocket 주소와 통신합니다. 다른 앱이나 클라우드에 직접 공유하지 않습니다.

프로젝트별 스킬 버튼은 프로젝트 폴더 경로, 선택한 SKILL.md 경로, 버튼 이름, 대상 AI 앱과 요청문을 `skill-workspaces.json`에 로컬 저장합니다. 스킬 목록을 위해 사용자 및 프로젝트의 skills 폴더에서 이름과 설명을 읽습니다. GitHub 저장소나 설치되지 않은 플러그인 캐시 전체를 자동 수집하지 않습니다.

사용자가 등록한 스킬 버튼을 누르면 프로젝트·스킬 파일 경로와 요청문을 선택한 GPT 또는 Claude 데스크톱 앱으로 전달합니다. 입력된 요청문과 전송 버튼을 확인할 수 있으면 전송하며, 그렇지 않으면 사용자가 앱에서 확인하도록 안내합니다. AI 앱은 요청에 따라 로컬 프로젝트·스킬 파일에 접근할 수 있으며, 해당 AI 서비스의 계정·권한·보관 정책이 적용됩니다. 허브는 AI 계정 비밀번호·쿠키를 수집하지 않으며 접근 승인이나 보안 확인을 대신 누르지 않습니다. 공유 작업 기록에는 요청문이나 프로젝트 파일 내용을 넣지 않습니다.

작업 기록은 이 PC에 저장되며, 사용자가 공유 설정에서 네트워크 폴더를 지정한 경우 PC 이름과 기록 내용이 해당 폴더를 함께 사용하는 PC에 공유됩니다. 프로젝트별 스킬 버튼 설정은 이 공유에 포함하지 않습니다.

문의는 [저장소](https://github.com/feed-mina/Workstation_Hub)의 이슈로 할 수 있습니다. 공개 이슈에는 토큰·계정 정보·개인 영상·집 주소를 올리지 마세요.
