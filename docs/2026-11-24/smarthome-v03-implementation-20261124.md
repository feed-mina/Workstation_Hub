# 스마트홈 0.3 구현과 설치 준비

목표는 방을 고르고 집 기기를 제어하며, 휴대폰에 내려받은 맘카 영상을 PC에서 보관하는 것입니다.

1. 방별 기기 제어와 영상 보관을 구현하고 앱 저장소에 게시했습니다.
2. Windows에서 가짜 기기·Google 응답과 생성한 영상으로 검사했습니다.
3. Store 업로드와 실제 PC 설치, 기기·개인 채널 시험은 아직 남아 있습니다.

## 현재 상태

- 구현·소스 게시 완료. 청소 시작·일시정지·복귀, 방 청소 동작 연결, 클래식·인기가요 목록 연결, 창문·건조기 상태 표시.
- 영상 폴더 수집·중복 확인·촬영 날짜 확인·원본 보관·날짜별 편집·비공개 전송·이어 보내기·결과 확인 구현.
- 자동 검증 통과. 32개 검사, 화면 상태 검사, 실제 600초 영상 생성·길이 확인, 창 회귀 시험 코드 컴파일.
- Store 제출용 0.3 패키지 생성·포장 검사 완료. Store 서명 전이며 설치 완료를 뜻하지 않습니다.
- Store 0.2는 인증 심사 중입니다. 기존 설치 앱은 유지했습니다.
- 0.3 Store는 미제출입니다. 브라우저 현재 주소를 확인하지 못해 컴퓨터 제어가 중단됐습니다.
- 0.3 설치 후 네 창 이동·작업표시줄 복원·병아리 메뉴와 실제 기기 제어는 아직 시험하지 못했습니다.

## 영상 보관 순서

사용자가 U+ 앱에서 갤러리에 저장 → 전송 도구가 맘카 앨범만 PC로 전송 → Hub가 중복과 재생 길이 확인 → 원본 보관 → 날짜별 편집 → 비공개 전송 → 처리 성공과 비공개 확인 → 다시보기.

전송이 실패하면 원본을 유지하고 다시 시도합니다. 유튜브가 받았는지 불분명하면 Studio 확인 전까지 새 전송을 멈춥니다. 늦게 온 원본은 기존 작업과 겹치지 않게 추가 편집합니다. 휴대폰 정리는 PC의 원본이 재생되는지 확인한 뒤 사용자가 직접 승인합니다.

## 첫 사용에서 할 일

연결 설정에서 집 연결을 확인하고 방과 기기를 연결합니다. 영상 보관에서 전송·보관 폴더와 별도의 영상 편집 도구 위치를 정합니다. 휴대폰 전송 도구는 맘카 앨범만 대상으로 설정합니다. 기존 Google 데스크톱 연결 파일을 선택하고 브라우저에서 직접 승인한 뒤 첫 편은 수동 비공개 전송으로 확인합니다.

15초 맘카 완성본은 원래 길이로 연결합니다. 하루 전체 10분은 하루에 걸친 사진 수집 경로가 필요합니다. 호환 카메라의 사진 수집은 구현했지만 맘카의 직접 연결 가능 여부는 미확인입니다. 사진이 부족하면 반복 장면이 생깁니다. 연결하지 않은 센서 값은 확인 불가로 표시합니다.
