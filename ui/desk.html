    왼쪽에서 설치된 스킬을 고르면 이 프로젝트의 버튼으로 저장할 수 있어요.

    GitHub 연결 전

    브라우저에서 본인 계정으로 로그인하고 아래 코드를 확인해 주세요.

    공식 GitHub CLI 인증입니다. 비밀번호는 Hub에 입력하지 않습니다.

    내 PC끼리 선택한 프로젝트만 공유

    전용 비공개 설정 저장소를 연결하면 목록과 공통 스킬 버튼을 공유할 수 있습니다. 폴더 경로·실행 위치·위치 예외·로그인 정보는 이 PC에 보관합니다.

    조직의 저장소가 보이지 않으면 GitHub의 조직 SSO·OAuth 앱 승인과 계정 권한을 확인한 뒤 새로고침하세요.

    이 PC의 폴더로 시작하기

    기존처럼 폴더를 선택해 로컬 프로젝트를 등록합니다. 경로와 실행 설정은 이 PC에 저장합니다.

    프로젝트 설정

    클라우드 선택은 실행 준비 설정입니다. AI 앱에서 같은 저장소·환경을 선택하고 요청을 확인해야 작업이 시작됩니다. 로컬 폴더 연결은 자동 복제·Push·Pull을 실행하지 않습니다.

    다른 PC의 설정과 충돌했습니다.

    원격 설정으로 바꾸거나, 이 PC의 공통 버튼 구성을 유지할 수 있습니다. 로컬 경로와 위치 예외는 보존합니다.
